# CAD柜体白模与机位

沿用用户语言，先读清图纸关系，再复用脚本推进。目标是准确、好改、构图可选；不要以少做必要细节来换速度。主流程：**尺寸记录 → 参数化白模 → 多机位小样 → 选定高清**。

## 从当前阶段继续

- 新建白模：读取 [尺寸与项目配置](references/project-format.md)，建立项目JSON，再调用脚本。
- 已有 `.blend` 调角度：保留原文件，配置 `mode: existing`，复用相机脚本，不重新建房间。
- 项目续改：先读项目JSON、最近的 `*-result.json` 和用户新要求；仅在缺少依据时回读图纸或建模代码。
- 白模不默认加载整套PBR、写实图像生成或艺术批评技能。对应任务出现时才读相关技能。脚本自包含，不要求MCP或云服务。

## 先锁定设计依据

1. 将平面、立面、现场照片分别编号，确认朝向、比例与对应柜体。有矢量CAD时优先提取坐标和标注；只有截图时明确已读到的尺寸。
2. 尺寸、来源、用户决定和估算记入 `decisions`。尺寸冲突集中处理一次；用户已指定“立面为准”等规则后持续沿用。区分缺失信息与已获授权的按比例补齐，后者直接推进并记录。
3. 不从“柜顶贴吊顶”推断未知原顶标高；保留柜顶、吊顶底、原顶三者关系。核对转角重叠、外露段、上柜总深、门板数量、拉手和海棠角。
4. 复用柜体、门板、抽屉面板和拉手。毫米统一换算为米；不修改设计来适应构图。组件不够时只增加所需局部几何，并保持可复现。

## 运行现成工具

`{skill}` 是本SKILL.md所在目录；其他路径使用任务内实际绝对路径。Python用当前可用运行时，Blender由PATH或macOS标准安装位置发现，也可指定 `--blender`。

```bash
python "{skill}/scripts/workflow.py" validate --project "{project}"
python "{skill}/scripts/workflow.py" build --project "{project}" --out "{out}/model"
python "{skill}/scripts/workflow.py" preview --project "{project}" --blend "{out}/model/model.blend" --out "{out}/proofs"
python "{skill}/scripts/workflow.py" final --project "{project}" --blend "{out}/model/model.blend" --out "{out}/final" --cameras A B
```

- build创建新场景；preview/final在后台加载副本，保存到独立路径，拒绝覆盖输入文件。
- 小样默认长边640；优先Workbench，图形后端失败时尝试低采样Cycles。高清默认长边2400、Cycles自适应采样与降噪，自动检测GPU；按质量调整，不机械提高采样。
- 同一批机位在一个Blender进程中完成；源文件与配置相同可命中缓存。只读状态摘要，故障时再看日志尾部，避免连续读完整日志。修改后不得误用旧小样。
- 建模参数变化时重新build；只改机位时复用模型。不要用existing绕过自己生成模型的参数过期检查。
- 默认不做复杂UV、不可见螺丝或滑轨；用户指定的拉手、分格、转角、收口和吊顶保留。可见边缘用小倒角，灰白明暗应读清门缝。

## 机位选择

首次通常给4—6个**有差别**的小样，编号并标注视高与焦距；按需求调整数量，不能只交几乎相同的角度。候选可含衣柜完整、衣柜自然比例、梳妆台近正面、门口全景。

- 用户指定1.5m或1.2m时按指定值；改视高不自动改变横竖幅或主体。无指定时可从1.5m开始，说明是默认值。
- 在36mm传感器基准下可先试24—35mm，28—35mm优先考虑自然比例；按实际小样判断。小于24mm提示检查边缘拉伸，不能把某焦距当作绝对“无畸变”保证。
- 同时考虑位置、朝向、主体在画面的位置、焦距、移轴与画幅。同机位换长焦主要改变裁切；相应后退/换机位才改变透视关系。垂直线优先通过水平相机加移轴保持。
- 露全与比例冲突时给完整广角和自然裁切的候选，并推荐一个；不得拉伸柜体。相机移到房间外或隐藏墙体时说明展示方式；hide_objects只用于明确的剖切展示，不能偷偷隐藏柜门或拉手。
- 看小样检查裁切、遮挡、边缘拉伸、门板数量、拉手与凳子是否入镜。脚本包围盒检查不等于遮挡检测或视觉验收。
- 用camera-proofs.png并排展示，说明推荐与取舍。用户选定或已明确授权你选最佳后再出对应高清；已有明确机位的修改不强制重选一整套。

## 检查与交付

建模后核对关键尺寸、立面和顶视关系、门缝、吊顶贴合、海棠角及明显穿插。脚本只查基础拓扑，不能声称CAD完全一致。若环境有blender-asset-qa，几何变更后按render场景做必要检查；保留真实门缝，不能为消除误报移动CAD尺寸。纯相机调整比较几何指纹，无需重跑全部建模检查。

交付所选PNG、对应Blender场景及简短尺寸/估算说明。场景含项目快照和渲染记录。保留图纸私有，避免旧新版同时进行高清渲染。只报告实际检查、输出与不确定项；没有对照实验不承诺提速或token节省比例。

各机位可能有不同画幅和墙体隐藏方式，继续通过项目JSON与脚本渲染；仅切换活动相机不会自动同步这些设置。
